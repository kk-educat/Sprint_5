# Финальный проект 5 спринта автоматизации курса Яндекс Практикум. Авто-тестирование сайта Stellar Burgers.

1. Основа для написания автотестов - фреймворки Selenium и Pytest.
2. Для установки необходимых зависимостей фреймворков и библиотек использовать команду:
    `python -m pip install -r requirements.txt`
3. Для запуска тестов проекта использовать команду:
    `python -m pytest`
